## Start from data you already have

- **JSON Schema: Generate Schema from This File** infers a schema from a
  document you already have.
- **JSON Schema: Generate Sample Data from This Schema** goes the other way,
  and can emit many instances as a JSON array or JSONL.
- **JSON Schema: Generate Types from This Schema** emits TypeScript, Python, Go,
  Rust, Java, C# and more.

Every generated instance is validated against the schema before you see it.
